# 🎬 Obsidian Media Add 🎬

Этот скрипт позволяет автоматически создавать Markdown-файлы для фильмов и сериалов в твоём хранилище Obsidian, используя данные из **The Movie Database (TMDb)**. Он поддерживает как фильмы, так и сериалы, а также может работать с текстом из буфера обмена или через аргументы командной строки.

## 🛠️ Как это работает?

1. **📋 Получение данных из буфера обмена**:
   - Скрипт автоматически извлекает название и год из текста, скопированного в буфер обмена.
   - Если текст на русском, он попробует найти фильм по оригинальному названию, транслитерированному или переведённому на английский.

2. **🔍 Поиск на TMDb**:
   - Скрипт ищет фильм или сериал по названию и году (если указан).
   - Если год не указан, он вернёт первый найденный результат.

3. **📂 Создание Markdown-файла**:
   - На основе данных из TMDb создаётся Markdown-файл с шаблоном, который включает:
     - Название, год, режиссёров, актёров, жанры, описание и постер.
     - Ссылки на режиссёров, актёров и жанры в формате, совместимом с Obsidian.

4. **🎯 Гибкость**:
   - Скрипт поддерживает как фильмы, так и сериалы.
   - Можно указать тип контента через флаги `-m` (фильмы) или `-t` (сериалы).
   - Если тип не указан, скрипт запросит его у пользователя.

### ✨ Главные особенности скрипта ✨

- 🔍 **Интеграция с TMDB API** – поиск фильмов и сериалов по названию и году.
- 🌍 **Автоматический перевод** – если фильм отсутствует в русскоязычной базе, скрипт сам переведёт название.
- 🔠 **Транслитерация** – корректный поиск даже при использовании русского алфавита.
- 🎯 **Точный и однородный поиск** – TMDB API позволяет добиться более точного поиска, сравнивая с OMDB. При этом все карточки на русском языке и имеют большую однородность за счёт локализации.
- 🛠 **Гибкая настройка** – поддержка кастомных шаблонов для карточек.


# 🚀 Использование


#### 1. **С использованием буфера обмена**:
   - Скопируй название фильма или сериала (например, "Интерстеллар 2014").
   - Запусти скрипт с флагом `--clipboard` или -с:
     ```bash
     py media_script.py --clipboard -m
     ```

#### 2. **С указанием названия и года**:
   - Запусти скрипт с аргументами `--title` и `--year`:
     ```bash
     py media_script.py --title "Интерстеллар" --year 2014 -m
     ```

#### 3. **Для сериалов**:
   - Используй флаг `-t`:
     ```bash
     py media_script.py --title "Игра престолов" --year 2011 -t
     ```

## 🐍 0. Установка Python

Если у вас каким-то образом не установлен **Python**, его необходимо установить. Скачайте его с [официального сайта](https://www.python.org/) и убедитесь, что добавили его в `PATH`.

Проверьте установку командой:

```bash
python --version
```

## 📥 1. Клонирование репозитория

Склонируйте репозиторий с GitHub:

```bash
git clone https://github.com/divohub/Obsidian-Media-Add.git
cd Obsidian-Media-Add
```

## 📦 2. Установка зависимостей

Установите зависимости одним из способов:

```bash
py -m pip install requests pyperclip deep-translator transliterate
```

или, если используете `requirements.txt`:

```bash
pip install -r requirements.txt
```

## 🔑 3. Получение TMDB API Key

1. Зарегистрируйтесь на [TMDB](https://www.themoviedb.org/).
2. Перейдите в **Настройки → API** и создайте API-ключ.
3. ⚠️ **Важно**: если вы в России, вам нужен **VPN** для доступа к API.

## 📂 4. Создание .env файла

Чтобы скрипт работал, нужно создать файл `.env` в корневой папке и добавить в него ключи:

```ini
OBSIDIAN_VAULT_PATH_MEDIA="путь_к_хранилищу"
TMDB_API_KEY="ваш_api_ключ"
```

- 📁 `OBSIDIAN_VAULT_PATH_MEDIA` – путь к папке в Obsidian, где будут сохраняться карточки.
- 🔑 `TMDB_API_KEY` – ваш ключ API для работы с TMDB. Он представляет собой строку из **32 символов** (буквы и цифры). Пример:

```ini
TMDB_API_KEY="abcd1234efgh5678ijkl9012mnop3456"
```

## 🚀 5. Запуск через Obsidian Shell

Скрипт можно запускать прямо из Obsidian через **Obsidian Shell Plugin**. Чтобы передавать название и год фильма из буфера обмена, добавьте флаг `-c`:

```bash
python /путь/к/скрипту/media_script.py -c
```

🔹 Обязательно указывайте **один из двух флагов**:

- 🎬 `-m` – для поиска **фильмов**
- 📺 `-t` – для поиска **сериалов**

Пример команды для поиска фильма:

```bash
py /путь/к/скрипту/media_script.py -c -m
```

Пример команды для поиска сериала:

```bash
py /путь/к/скрипту/media_script.py -c -t
```
Не забудьте указать **путь до места**, где у вас находится скрипт. 

📌 Вы также можете назначить **горячую клавишу** для удобного вызова.

## 📊 6. Использование Dataview для отображения

Можно настроить **Dataview** для удобного сбора рекомендаций в виде таблицы. Пример запроса:

```dataview
TABLE year, director, genre, substring(description, 0, 70) + "..." AS description
WHERE type = "movie"
WHERE watched != true
SORT year DESC
```

Этот код создаст таблицу с фильмами, которые ещё не просмотрены.

## 🎨 Шаблон Markdown

Скрипт создаёт файл в формате Markdown с использованием следующего шаблона:

```
---
title: {title}
year: {year}
director: {directors}
genre: {genres}
description: {description}
type: {content_type}
cover: {poster_url}
watched: false
---

# {title}

{poster_md}

**Год:** [[{year}]]  
**Режиссёр:** {directors_links}  
**Актёры:** {actors_links}  
**Жанр:** {genres_links}  

## Описание
{description}

### References

[[Рекомендации]]
```
---
### 🔑 Переменные шаблона

При желании можно изменить этот шаблон, вот какие переменные доступны:

- **`{title}`**: Название фильма или сериала.
    
- **`{year}`**: Год выпуска.
    
- **`{directors}`**: Режиссёр(ы).
    
- **`{genres}`**: Жанры.
    
- **`{description}`**: Описание.
    
- **`{content_type}`**: Тип контента (`movie` или `tv`).
    
- **`{poster_url}`**: Ссылка на постер.
    
- **`{poster_md}`**: Постер в формате Markdown.
    
- **`{directors_links}`**: Ссылки на карточки режиссёров (в формате Obsidian).
    
- **`{actors_links}`**: Ссылки на карточки актёров (в формате Obsidian).
    
- **`{genres_links}`**: Ссылки на жанры (в формате Obsidian).
